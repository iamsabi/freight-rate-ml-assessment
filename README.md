# Freight Rate Prediction Challenge

This repository contains my solution for the Machine Learning Engineer Assessment focused on predicting freight rates using historical shipment data and machine learning techniques.

---

## Project Overview

The objective of this project is to develop a regression model capable of accurately predicting freight rates based on shipment characteristics. The solution includes data preprocessing, feature engineering, model training, evaluation, and prediction generation for the provided validation dataset.

---

## Dataset

The project uses the following datasets provided as part of the assessment:

- `train_test.csv` – Labeled dataset used for model training and validation.
- `validation.csv` – Unseen dataset used for final predictions.
- `validation_predictions_template.csv` – Template for the final submission file.
- `december_chart_inputs.csv` – Dataset used to generate the December prediction chart.

---

## Solution Approach

### 1. Data Loading & Exploration

- Loaded all datasets using Google Colab.
- Performed exploratory data analysis to understand feature distributions, missing values, and data types.

### 2. Data Preprocessing & Feature Engineering

- Handled missing values using median imputation where appropriate.
- Extracted date-based features such as month, day, day of week, quarter, and week.
- Applied frequency encoding to pickup and delivery locations.
- Applied one-hot encoding to categorical features such as equipment type.
- Ensured feature consistency across training, validation, and December datasets.

### 3. Model Training & Validation

The development dataset was split into training and validation sets.

The following regression models were implemented and evaluated:

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor
- CatBoost Regressor

Models were evaluated using regression metrics including R² Score and Mean Squared Error (MSE).

### 4. Final Model

Based on the evaluation results, **CatBoost Regressor** was selected as the final model due to its superior predictive performance.

### 5. Prediction Generation

The trained model was used to generate predictions for:

- `validation.csv`
- `december_chart_inputs.csv`

The required submission files were generated successfully.

---

## How to Run

1. Install the required dependencies:

```bash
pip install -r requirements.txt
```

2. Place the provided datasets in the appropriate directory.

3. Open and run the notebook (`Freight_Rate_Prediction.ipynb`) in Google Colab or Jupyter Notebook.

4. Generate:

- `validation_predictions.csv`
- `december_predictions.csv`

5. Run the scoring script:

```bash
python score.py --predictions validation_predictions.csv --december-predictions december_predictions.csv
```

The scorer will generate the December prediction chart.
